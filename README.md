# 🛒 KOTSHOP

A simple **desktop purchasing management application** built with **Python**. KOTSHOP simulates a shopping system where customers can select products, manage quantities, and receive an automatically generated receipt.

The application focuses on implementing real purchasing operations through a simple and intuitive graphical interface.

## ✨ Features

* 🛍️ Browse products organized into categories.
* 🖱️ **Left-click** a product to increase its quantity.
* 🖱️ **Right-click** a product to decrease its quantity.
* 💰 Automatically calculates the total purchase cost.
* 🧾 Generates a detailed purchase receipt.
* 💵 Prevents purchases that exceed the customer's available budget.
* 🎨 Clean and user-friendly desktop interface.

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
